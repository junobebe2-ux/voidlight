VOIDLIGHT is an original arena-survival game for make.fun's best-game-01: you are the last lantern-light in a dark void, fighting waves of shades. Auto-fire bolts, a nova burst, XP shards and level-up upgrades. Vanilla canvas 2D, playable offline in a desktop browser -- all graphics and sound generated from code, no network needed.

## Run it

```sh
python3 -m http.server --directory game 8000
# then open http://localhost:8000 in a desktop browser
```
